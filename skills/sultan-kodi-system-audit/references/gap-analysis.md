# Gap analysis against similar systems

Goal: find what comparable products have that this one lacks, and what is common practice that it skips.
1. Name the category in one line (for example "booking site for a clinic", "internal CRM", "storefront").
2. Use web search to find 3 to 5 comparable products or well-known open-source equivalents. Open their public pages, docs and feature lists. Record the source of each claim.
3. Build a table: capability | present here (file or screen) | present in comparables | gap size | note. Group by: onboarding, core flow, account and billing, admin, notifications, reporting, integrations, security and privacy, accessibility, performance, support and help.
4. Mark each gap as table stakes (users expect it), differentiator, or not relevant here, with a reason.
5. Feed the table stakes into `opportunities.md` ranking. Do not copy protected content, branding or text from other products; describe capabilities only.
