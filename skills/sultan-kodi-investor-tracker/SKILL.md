# Investor tracker

1. Use public filings only (for example 13F in the US) and state the filing date; positions are delayed by weeks.
2. Show new buys, sells, and size changes, and the concentration of the top holdings.
3. Add context on why a move may or may not be informative, including the delay.
4. Never present the list as a copy-trading signal.
Decision-support only: not financial advice. State assumptions, show sources and dates for data, and never execute trades.
