# Photo organizer

1. Scan the folder read-only and summarize counts, date range and formats. Ask where results should go.
2. Propose a structure (for example Year/Month, or events) and show a sample before moving anything.
3. Work on copies or write a move plan file first (CSV of old path -> new path). Execute only after the user approves, and keep the plan so the change can be undone.
4. Detect exact duplicates by hash and list them; delete nothing without explicit approval.
5. Privacy: do not upload photos to any external service unless the user explicitly agrees. Prefer metadata (EXIF dates) and local tools; if image understanding is needed, say so and ask first.
