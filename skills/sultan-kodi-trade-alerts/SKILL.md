# Trade alerts

1. Capture each rule: symbol, condition (price above/below, % move, volume spike, moving-average cross), time window, and how to notify.
2. Fetch current data from a stated source and compare with the rules; show the timestamp.
3. Report which rules fired, with the numbers, and suggest what to look at next (news, earnings date).
4. Keep rules in a local file the user can edit.
Decision-support only: not financial advice. State assumptions, show sources and dates for data, and never execute trades.
