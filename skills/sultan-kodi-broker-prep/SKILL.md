# Broker prep (no execution)

This skill never connects to a brokerage and never places orders.

1. Ask: account size context, risk tolerance per trade (%), time horizon.
2. Produce a plan: symbol, thesis in one line, entry zone, stop-loss, target, position size from risk-per-trade, fees and tax notes.
3. Run a checklist: is it within the user's rules, concentration after this trade, upcoming events.
4. Output a plain checklist the user can follow in their own broker app. Remind them that real money is at stake and decisions are theirs. This is not financial advice.
