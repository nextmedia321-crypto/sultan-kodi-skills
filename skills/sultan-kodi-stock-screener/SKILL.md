# Stock screener

1. Turn the user's goals into explicit numeric criteria and confirm them.
2. Get data from a stated source, apply filters, and list matches with the key numbers and the data date.
3. Flag data problems (stale, one-off earnings, thin liquidity) and show what almost passed.
4. Results are candidates for research, not recommendations.
Decision-support only: not financial advice. State assumptions, show sources and dates for data, and never execute trades.
