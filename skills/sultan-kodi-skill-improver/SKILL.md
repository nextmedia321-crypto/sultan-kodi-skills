# Skill improver

1. Review what happened: where the agent was corrected, where it guessed wrong, where steps were missing or repeated.
2. For each issue record: situation, what went wrong, root cause, and whether it belongs in an existing skill or a new one.
3. Propose concrete edits as before/after text for the skill file, kept small and specific. Prefer deleting vague lines over adding more.
4. Suggest new skills only for procedures that recurred at least twice.
5. Never edit a skill file without the user's approval. Keep a running log in a plain markdown file in the project.
