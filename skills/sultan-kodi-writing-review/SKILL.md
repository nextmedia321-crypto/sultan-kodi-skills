# Writing review

1. Ask for or locate the style rules (a file, a brand voice doc, or the user's description). If none exist, default to: plain words, short sentences, active voice, one idea per paragraph.
2. Read the whole text once before editing anything.
3. Check: clarity, tone fit for the audience, consistency of terms and numbers, spelling and grammar, repeated phrases, claims that need a source.
4. Return a table: location | problem | suggested rewrite | rule it breaks. Keep suggestions small; do not rewrite what works.
5. Finish with a cleaned version only if the user asked for it. Match the language of the text; for Hebrew keep punctuation correct for right-to-left.
